# Online-shopping-sales-data

电商网购销售数据清洗、Pandas分析、SQL分析与可视化项目

## 一、项目简介

本项目基于约5000条电商网购销售数据，使用 Python、Pandas、MySQL 和 Matplotlib 对电商订单数据进行清洗、分析和可视化。
项目主要从订单、商品、商品类别、用户、地区和时间等维度进行分析，了解销售额变化、商品销售情况以及不同地区和用户群体的销售表现。

## 二、项目内容

### 1. 数据清洗
使用 Pandas 对原始电商销售数据进行清洗，主要包括：

- 缺失值处理
- 重复数据处理
- 异常数据检查
- 时间字段处理
- 商品价格、购买数量和订单金额检查
- 订单状态及退款状态检查
- 筛选有效订单

本项目将：
> 订单状态 = 已完成  
> 退款状态 = 无退款

以上两种数据作为有效订单进行后续分析。

### 2. SQL数据分析

使用 MySQL 对清洗后的数据进行分析，主要包括：
- 有效订单数量
- 总销售额
- 平均每笔订单消费金额
- 月度销售额
- 销售额最高及最低月份
- 商品销量最高的商品
- 商品销售额最高的商品
- 销售额最高的商品类别
- 销售额 TOP5 商品
- 销售额最高的省份
- 不同性别用户销售额
- 订单数量最多的省份
- 10月与11月销售额变化
- 10月与11月各商品类别销售额对比

### 3. Pandas数据分析

使用 Pandas 对有效订单进行进一步分析，包括：
- 月度销售额分析
- 季度销售额分析
- 商品销售额排名
- 销售额 TOP5 商品
- 商品类别销售额占比
- TOP5销售省份
- 用户消费金额分布
- 男女性别用户销售额对比
- 10月与11月销售额对比
- 10月与11月各商品类别销售额对比

### 4. 数据可视化

使用 Matplotlib 将分析结果进行可视化，主要包括：
- 月度销售额趋势图
- 季度销售额柱状图
- 商品销售额排名图
- 商品类别销售额占比图
- 用户消费金额分布图
- 男女用户销售额占比图
- TOP5省份销售额图
- 销售额 TOP5 商品图
- 10月与11月销售额对比图
- 10月与11月各商品类别销售额对比图
